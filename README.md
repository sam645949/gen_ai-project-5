# Face Detection Using Python

## 1. Project Description
Face Detection Using Python is a computer vision project that identifies and detects human faces in images or through a live webcam feed. The project uses image processing techniques and computer vision libraries to locate faces in real time.

## 2. Objective
The main objective of this project is to develop a simple face detection system that automatically identifies human faces from images or video streams.

## 3. Features
- Detects human faces in images.
- Supports real-time face detection using a webcam.
- Draws rectangular bounding boxes around detected faces.
- Processes images and video frames.
- Provides a simple and beginner-friendly implementation.

## 4. Technologies Used
- **Python** – Main programming language.
- **OpenCV** – Computer vision and image processing.
- **Haar Cascade Classifier** – Detectv
